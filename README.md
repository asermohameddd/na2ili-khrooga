# **Na2ili Khrooga_نقيلي خروجة**

**Na2ili Khrooga** is a responsive Egyptian takeout recommendation website designed to help users discover suitable places based on their budget and group size.

The website allows users to enter the number of people and the average amount they want to spend per person and the total budget. The website provides a selection of suitable takeout suggestions.

🌐 **Live Demo**  
https://asermohameddd.github.io/na2ili-khrooga-_-/


## Project Idea

The main idea behind **Na2ili Khrooga** is to make choosing a place to hang out easier.

Instead of spending a long time searching for places and trying to calculate whether they fit the available budget, the user simply enters:

- Number of people
- Average budget per person
- Total budget

The website displays suitable takeout recommendations.

Users can also explore additional suggestions using the Show More functionality.

## Features

### Takeout Recommendations

The website displays takeout suggestions that match the user's budget.

Each suggestion can include information such as:

- Place
- Food type
- Estimated price
- Description
- Additional information

### Dynamic Results

The recommendations are generated dynamically depending on the user's inputs.

Changing the number of people or the available budget changes the results accordingly.

### Show More

The website initially displays a limited number of recommendations to keep the interface clean.

Users can select Show More to display additional suggestions.

### Filtering and Sorting

The JavaScript (Made with AI) functionality allows the website to handle different recommendation and filtering operations, making it easier for users to find suitable options.

### Responsive Design

The website is designed to work across different screen sizes, including:

- Desktop
- Laptop
- Tablet
- Mobile

The layout adapts to smaller screens while keeping the main functionality accessible.

### Interactive User Interface

The website includes interactive elements such as:

- Budget input
- People count input
- Buttons
- Recommendation cards
- Filters
- Dynamic results
- Show More functionality
- Navigation interactions

#### What JavaScript Does

The JavaScript is responsible for most of the website's dynamic and interactive behavior.

It handles:

- **User Input:** JavaScript reads the number of people and the average budget and the total budget entered by the user.
- **Dynamic Rendering:** Instead of displaying every recommendation manually, JavaScript dynamically generates and displays the appropriate recommendation cards.
- **Filtering:** JavaScript handles filtering operations to help users narrow down the available recommendations.
- **Show More Functionality:** JavaScript controls the number of recommendations displayed and allows users to load additional suggestions without reloading the page.
- **Interactive Elements:** JavaScript controls different interactions throughout the website, including buttons, forms, filters, navigation elements, and dynamic sections.
- **Validation:** JavaScript can check user inputs and prevent invalid values from being processed.
- **Dynamic Content Updates:** The page can update its content based on user actions without requiring a full page reload.

## How to Use

1. Open the Na2ili Khrooga website.
2. Enter the number of people.
3. Enter the average amount you want each person to spend.
4. Enter the total budget of all people.
5. Submit the form.
6. Suitable takeout recommendations are displayed.
7. Use the available filters to explore different options.
8. Select Show More to view additional recommendations.
